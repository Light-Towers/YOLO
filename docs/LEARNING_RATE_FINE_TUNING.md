# 为什么增量训练需要降低学习率？

## 核心原因

增量训练（Fine-tuning）时，模型已经具备了较好的初始参数，如果使用原始学习率会导致：
1. **破坏已学习的特征** - 参数更新步长过大，破坏 Backbone 已学到的通用特征
2. **过拟合风险** - 小数据集 + 大学习率 = 快速过拟合
3. **训练不稳定** - 梯度震荡，难以收敛

---

## 直观理解：学习率 = 参数更新步长

```
学习率决定了每次迭代中参数移动的幅度
─────────────────────────────────────────────

原始训练（从零开始）:
  初始参数: 随机（接近 0）
  目标: 学习从零开始
  策略: 大步长快速探索
  学习率: lr0 = 0.01 ✅

增量训练（基于已训练模型）:
  初始参数: 已优化（接近最优）
  目标: 微调适应新数据
  策略: 小步长精细调整
  学习率: lr0 = 0.001 或更低 ✅
```

---

## 类比：优化函数

假设我们在优化损失函数 `L(w)`：

```
损失函数曲面
     ▲
     │       ╲
     │        ╲  最小值
     │         ●
     │        / ╲
     │       /   ╲
     │  ●───●─────●← 当前参数（已训练）
     │  /
     │ /
     │/
     └────────────────▶ 参数 w
```

| 场景 | 当前位置 | 步长 | 结果 |
|------|----------|------|------|
| 原始训练 | 远离最小值 | 大 (0.01) | 快速接近最优 ✅ |
| 增量训练 | 已接近最小值 | 大 (0.01) | 跳过最优，来回震荡 ❌ |
| 增量训练 | 已接近最小值 | 小 (0.001) | 精细调整到最优 ✅ |

---

## 技术解释

### 1. 参数更新公式

```
w_new = w_old - lr * ∇L(w)
       ↑         ↑      ↑
    新参数    旧参数 学习率 × 梯度
```

- `lr` 越大 → 参数更新幅度越大
- 梯度 `∇L` 固定，通过 `lr` 控制更新步长

### 2. 损失函数曲面

在接近最优解时：
- 损失函数曲面趋于平坦
- 梯度变小，但仍可能有噪声
- 大学习率会导致参数在最优解附近震荡

```
小学习率:  ●─────●─────● (平稳收敛)
           ↑最优解

大学习率:  ●─●   ●─●   ●─● (震荡，难以收敛)
          ↕  ↕   ↕  ↕
          震荡范围大
```

## 实验对比

### 场景：使用 yolo11m-obb 模型微调

| 学习率 | 收敛情况 | 验证集 mAP | 最终效果 |
|--------|----------|------------|----------|
| **lr0=0.01** (原始) | 震荡，不收敛 | 波动大 | 比预训练模型还差 ❌ |
| **lr0=0.001** | 稳定收敛 | 平稳上升 | 改善性能 ✅ |
| **lr0=0.0001** | 收敛缓慢 | 最终最优 | 数据量少时推荐 ✅ |

---

## 常见学习率设置

| 训练类型 | 推荐学习率 | 学习率衰减 |
|----------|------------|------------|
| 从零训练 | `lr0=0.01` | `lrf=0.01` (衰减到 0.0001) |
| 微调（数据多） | `lr0=0.001` | `lrf=0.1` |
| 微调（数据少） | `lr0=0.0001` | `lrf=0.1` |
| 仅训练 Head | `lr0=0.0001` | `lrf=0.1` |

## YOLO 代码示例

### 原始训练

```python
model = YOLO('yolov8s-obb.pt')  # 预训练权重
model.train(
    data='dataset.yaml',
    epochs=300,
    lr0=0.01,       # 初始学习率
    lrf=0.01,       # 最终学习率 = lr0 * lrf = 0.0001
    # cos_lr=True,  # 余弦退火学习率调度
)
```

### 增量微调

```python
model = YOLO('output/models/yolov8s-obb/exp_v17/weights/best.pt')
model.train(
    data='merged_dataset.yaml',
    epochs=100,
    lr0=0.001,      # 降低到 1/10
    lrf=0.1,         # 最终学习率 = lr0 * lrf = 0.0001
    freeze=10,       # 冻结 Backbone
    # cos_lr=True,
)
```

## 调试技巧

### 1. 如何判断学习率是否合适

| 现象 | 问题 | 解决方案 |
|------|------|----------|
| loss 不下降，或者震荡剧烈 | 学习率过大 | 降低 10 倍 |
| loss 下降极慢 | 学习率过小 | 增加 10 倍 |
| 验证集 mAP 不升反降 | 过拟合 | 降低学习率 + 数据增强 |

### 2. 学习率预热 (Warmup)

```python
warmup_epochs=3,      # 前 3 轮用小学习率预热
warmup_momentum=0.8,
warmup_bias_lr=0.1,
```

预热期间学习率从 0 线性增长到 `lr0`，避免初始震荡。

### 3. 动态调整

```python
# 使用余弦退火 (默认已启用)
cos_lr=True,

# 使用学习率查找器 (推荐)
model.tune(data='dataset.yaml')
```

---

## 总结

| 方面 | 从零训练 | 增量训练 |
|------|----------|----------|
| **初始参数** | 随机 | 已优化 |
| **学习率** | 大 (0.01) | 小 (0.001 或更低) |
| **训练轮数** | 多 (300) | 少 (50-100) |
| **策略** | 大幅探索 | 精细调整 |
| **风险** | 欠拟合 | 过拟合、破坏特征 |

---

*核心思想：增量训练是在已优化的基础上微调，需要更精细的步长（小学习率）*
